# 2NET Rastreamento

Personalização inicial do Traccar Client para a 2NET TELECOM.

## Alterações
- Nome visual: 2NET Rastreamento
- Logo e ícone da 2NET TELECOM
- Cores da identidade visual 2NET
- Logo exibida na tela principal
- Nome do pacote Flutter alterado para `net_rastreamento`
- Versão inicial: `1.0.0+1`
- Deep link Android/iOS preparado para `br.com.2net.rastreamento`

## Observação sobre Firebase
Os identificadores nativos e arquivos Firebase originais foram preservados nesta primeira etapa para evitar quebra do build. Para uma publicação própria na Google Play/App Store, o próximo passo recomendado é criar os projetos Firebase da 2NET e então trocar os Bundle IDs/Application IDs e os arquivos de configuração.

## Servidor
O endereço do servidor de rastreamento continua configurável pelo aplicativo. Nenhum endereço de servidor 2NET foi inventado ou fixado nesta etapa.
